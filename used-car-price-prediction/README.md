# Used Vehicle Valuation and Price Prediction
This repository contains a university applied machine-learning assignment comparing Multiple Linear Regression, Random Forest Regression, and a Fully Connected Neural Network.

## Dataset
The notebook downloads the zsarpong/10-million-used-car-listings dataset through KaggleHub.

## Run

1. Install dependencies from requirements.txt.
2. Authenticate with Kaggle if required by KaggleHub.
3. Open used_vehicle_price_prediction.ipynb.
4. Run the training cells in order.
5. Run the prediction interface only after model artifacts are saved.
