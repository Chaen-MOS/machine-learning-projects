# Machine Learning Experiments

This repository contains three machine learning projects I worked on during my studies at Universiti Tunku Abdul Rahman (UTAR).

Most of these projects involved preparing datasets, training different models, comparing their performance, and understanding why some models worked better than others.

## Projects

### 1. Used Car Price Prediction

This project focuses on predicting used car prices based on features such as mileage, manufacturing year, brand, and vehicle specifications.

We trained and compared three regression models:
- Linear Regression
- Random Forest
- Fully Connected Neural Network (FCNN)

**Tools:** Python, Pandas, Scikit-learn, TensorFlow/Keras

Random Forest achieved the best results among the three models in our experiments.

### 2. Spam Email Classification

For this project, we used the Spambase dataset to classify emails as spam or non-spam.

We explored several classification methods:
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)

**Tools:** R

We also worked with data preprocessing, PCA, and model evaluation to compare the different approaches.

### 3. COVID-19 ICU Prediction

This project explores whether machine learning models can predict COVID-19 ICU occupancy in Malaysia using historical COVID-19 data.

The models we experimented with include:
- Linear Regression
- Lasso Regression
- Artificial Neural Network (ANN)
- K-Nearest Neighbors (KNN)

**Tools:** Python, Scikit-learn, TensorFlow/Keras

We compared different models and data splitting approaches to understand how they affected prediction results.

## About

These projects were completed as part of my university coursework. I've kept them here as a record of my machine learning studies and the experiments I worked on.

I'm also gradually cleaning up the code and documentation to make the projects easier to understand and reproduce.
